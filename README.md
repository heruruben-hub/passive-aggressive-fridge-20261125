This is my entry for the make.fun bounty "Notes From a Passive-Aggressive Fridge".

The program writes a single note that a smart fridge leaves for its owner, dry and petty, the sort of thing a smug appliance would put on its door screen.

The note hands the leftovers seniority over the person who forgot them, because six days at 3°C is apparently enough to earn tenure in this house.

Running `python3 main.py` writes the note to `/output/entry.txt`, one line, ready for the judge.
